#C++ Modular Calculator
A professional-grade calculator build with Obkect-Oriented Programming (OOP)  in C++.

##Project Structure
-`Calculator.h`: The header file containing the class blueprint and function prototypes
-`Calculator.cpp`: The implementation of the math logic.
-`simpleClassCalculator.cpp`: The main Program; for designing the user experience.

##How To Compile and Run
To link the modular files and execute the program, run:
```bash
g++ simpleClassCalculator.cpp Calculator.cpp -o calculator && ./calculator
